# SREDA100

Генератор типографического брутализма (Organic Aggression Engine).
Версия: **v22.0**

## Описание
Скрипт генерирует статичные плакаты и видео с жесткими растровыми математическими искажениями. Поддерживает несколько стилей и случайную цветовую инверсию (ч/б или б/ч), создавая уникальные генеративные дизайн-элементы.

## Установка
Скрипт использует стандартные пакеты и `ffmpeg` для видео.
Требования:
- Python 3.x
- `Pillow`, `numpy`
- `ffmpeg` (установленный в системе)

## Запуск
По умолчанию скрипт берет текущий день недели и запускает рандомный стиль с рандомной инверсией цвета:
```bash
python sreda100.py --video
```

Для батч-генерации (например, 5 тестов):
```bash
python sreda100.py --video --batch 5
```

Можно указать специфичный день:
```bash
python sreda100.py --video --day FRIDAY
```

Специфичный стиль:
```bash
python sreda100.py --video --style ink_bleed
```

**Доступные стили:** 
- `classic` (оригинальный)
- `pattern` (заливка паттерном из слов)
- `outline` (контурная типографика)
- `micro_typo` (базовый с добавлением глитчующей меты по углам)
- `feedback` (аналоговое смазывание а-ля ксерокс)
- `ink_bleed` (растекающаяся краска)
- `random` (выбирает из вышеперечисленных)
