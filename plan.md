# Plan: Интеграция SREDA100 v22.0

## Context
Пользователь утвердил 5 стилей из прототипов: `micro_typo` (с метой), `outline`, `pattern`, `feedback`, `ink_bleed` (без черных краев). И попросил сохранить текущий `classic` стиль. Цветовая схема должна быть случайной: иногда ч/б, иногда б/ч (инверсия).

## Goal
Выпустить релиз v22.0: единый скрипт с флагом `--style` (выбор стиля или random), исправленным багом краев (edge smearing) и рандомной инверсией цветов. И запустить тестовый рендер 5 видео.

## Approach
1. Склеить логику всех 6 стилей в единый пайплайн в `sreda100.py`.
2. Флаг `--style` по умолчанию `random` (выбирает 1 из 6 вариантов для каждого запуска).
3. Рандомная инверсия: скрипт с вероятностью 50% добавляет `-vf negate` в ffmpeg, обеспечивая чередование черного и белого фонов.
4. Багфикс краев: встроить `valid_mask` в `warp_rgba`, чтобы крайние пиксели не размазывались в сплошные заливки при сильных искажениях.
